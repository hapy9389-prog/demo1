# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository layout

The repo root only contains one project: `ai-chatbot/` (a Next.js app). All commands below are run from inside `ai-chatbot/`.

## Project state

`ai-chatbot/` is currently an unmodified `create-next-app` scaffold — the App Router boilerplate (`app/layout.tsx`, `app/page.tsx`, `app/globals.css`) has not yet been built out into an actual chatbot. There is no backend, API route, database, or chat UI yet. Don't assume any chatbot-specific architecture exists; check `app/` for what's actually there before describing structure.

## Commands

Run from `ai-chatbot/`:

```bash
npm run dev      # start dev server (http://localhost:3000)
npm run build    # production build
npm run start    # serve the production build
npm run lint     # eslint (flat config in eslint.config.mjs)
```

No test runner is configured yet.

## Stack

- Next.js 16 (App Router), React 19, TypeScript (strict mode)
- Tailwind CSS 4 via `@tailwindcss/postcss` (no `tailwind.config`; Tailwind 4 configures via CSS in `app/globals.css`)
- Path alias `@/*` maps to the `ai-chatbot/` root (see `tsconfig.json`)
- ESLint flat config extends `eslint-config-next` (core-web-vitals + typescript)

## Notes specific to this repo

- `ai-chatbot/AGENTS.md` is auto-generated by `next dev` on every run (see `node_modules/next/dist/server/lib/generate-agent-files.js`) and points to `node_modules/next/dist/docs/` for framework-specific guidance, since this Next.js version may include breaking changes not reflected in training data. It will keep re-appearing as an uncommitted change — that's expected; commit it along with other work rather than fighting it.
