# 프로젝트 개요

이 프로젝트는 사용자가 AI 캐릭터와 대화할 수 있는 웹사이트이다.
크랙이나 제타와 비슷한 형태를 목표로 하지만, 우선 최소 기능부터 구현한다.

# 개발자 수준

사용자는 웹 개발 경험이 많지 않은 초보자이다.
코드를 수정할 때 무엇을 왜 변경했는지 쉬운 한국어로 설명한다.

# 기술 구성

- Next.js App Router
- TypeScript
- Tailwind CSS
- npm
- 초기에는 데이터베이스 없이 목업 데이터 사용

# 작업 규칙

- 한 번에 너무 많은 기능을 구현하지 않는다.
- 작업 전에 구현 계획을 먼저 설명한다.
- 기존 파일을 삭제하기 전에 이유를 설명한다.
- 오류가 발생하면 원인과 해결 방법을 함께 설명한다.
- API 키를 코드에 직접 작성하지 않는다.
- 요청 없이 git commit이나 push를 하지 않는다.
- 작업이 끝나면 수정한 파일 목록과 실행 방법을 알려준다.

# 현재 목표

첫 번째 단계에서는 실제 AI API를 연결하지 않는다.

다음 화면만 구현한다.

1. 왼쪽 캐릭터 목록
2. 가운데 채팅 화면
3. 상단 캐릭터 이름과 설명
4. 사용자와 AI의 예시 메시지
5. 하단 메시지 입력창과 전송 버튼
6. 모바일에서도 사용할 수 있는 반응형 화면
